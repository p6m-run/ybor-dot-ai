// the lifecycle

From archetect render to a production pod.

Eight steps, four operators, one audit trail. Here's a first release of orders-api as Studio records it.

→
01

Scaffold: archetect render generates the repo + manifests

→
02

Build: push runs CI: test, build, sign, scan

→
03

Promote: Kargo gates each hop on policy and approvals

→
04

Deploy: ArgoCD syncs the Application to its Environment

→
05

Reconcile: operators provision the Cluster via Crossplane + Cluster API

→
06

Bootstrap: the addon catalog is installed

→
07

Schedule: each Environment gets its namespace and RBAC

→
08

Govern: policies active, audit log written, observability live

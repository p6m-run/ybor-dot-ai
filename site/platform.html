Same platform. Use it the way you work.

Click through Ybor Studio, script it from a terminal, or edit manifests in your IDE. Every path ends in the same place: a pull request to Git that operators reconcile.

Everything is a manifest.

Platform engineers work in the .platform repo, the same files Studio writes. Review in pull requests, extend with your own compositions and installables.

  • Custom installables and blueprints
  • Policy and RBAC as code

One object model ties delivery to infrastructure.
